◆ BackendMode

enum class eonc::log::BackendMode
strong

How queued log records reach the sinks.

Thread runs Quill's own backend thread. Manual runs no thread at all: the thread that logs polls the queue itself through poll(), flush() and shutdown(), so a client can be strictly single threaded.

Write every queued record to the sinks and flush the sinks.

In Manual mode only the thread that started the backend can do this; a call from another thread leaves the records queued for that thread. In Thread mode the backend thread does the work and this returns once it has.

◆ start_client_backend()

BackendMode eonc::log::start_client_backend ( BackendMode mode)
inlinenoexcept

Start draining the client queue, once.

Later calls do nothing.

Manual installs an exit handler that drains the queue, since Quill's own exit handler belongs to its backend thread. A backend that is already running (a test fixture started one) is left in charge.

Returns
the mode now in effect.
