Detailed Description

Exact Gaussian elimination of a stable physical mass-weighted harmonic bath.

All nonpositive complementary curvatures are promoted to reaction coordinates. The measured Hessian defines a local quadratic model; this class does not assert that an anharmonic potential has a globally quadratic bath.
