Detailed Description

Exact nonnegative harmonic-reference links in mass-weighted coordinates.

tau = beta*hbar/N. Add correction(q) to the sum of physical bead energies; the physical energy zero is retained. The residual-potential splitting is second order, and is exact only when the residual commutes with the reference. This action does not define a real-time transmission factor or rate prefactor.
