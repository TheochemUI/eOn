Detailed Description

Fixed-energy line-integral nudged elastic band (LI-NEB) through rgsaddle: Ásgeirsson, Arnaldsson and Jónsson, J.

Chem. Phys. 148, 102334 (2018). Needs -Dwith_rgsaddle=true against a rgsaddle that exports the lineb C API (rgsaddle_lineb_solve). The built-in ring-polymer Instanton job is unchanged.
