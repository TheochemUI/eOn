Round-to-nearest-even value of the exact sum of x[i] * y[i].

An exact zero returns +0. A non-finite input returns the plain IEEE sum, so NaN and infinity propagate as they would without this function.

const double * y,
std::size_t n )
nodiscard

A fixed summation tree: four lanes (term i goes to lane i mod 4, each lane a left-to-right sum of rounded products), then (l0 + l1) + (l2 + l3).

Not exact, but every operation is a single IEEE multiply or add in an order this translation unit fixes (it is compiled without contraction), so the bits match on every compiler, Eigen release and CPU. For bulk products that set a vector, not a branch.
