The solid-state dimer, including a frozen cell, accepts a converged point only when the projected joint Hessian has one eigenvalue below -1e-4, and keeps a flat negative curvature running until the force is within 0.005 of that curvature. A higher-index point is left along its softest negative mode. `[Solid State] index_check` is on by default and is ignored unless the solid-state search is enabled.
