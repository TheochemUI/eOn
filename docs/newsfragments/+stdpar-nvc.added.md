Meson `-Dstdpar=cpu|gpu` turns on nvc++ `-stdpar=multicore|gpu` for the NEB image-force `std::execution::par` path without TBB. `-Dstdpar=gpu` also passes `-gpu=cc80,cc90` (override with `-Dstdpar_gpu_cc=`). GCC/Clang still use `-Dwith_parallel_neb=true`. Morse atom loops stay on the host. `QMC_GPU` is a QMCPACK flag, not an eOn option.
