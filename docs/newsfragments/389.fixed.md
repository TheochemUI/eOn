Classical pair pots (LJ, Morse, LJCluster, QSC) re-use a
``thread_local eonc::VesinNeighbors`` across force evaluations and no longer
``vesin_free`` before every ``compute``, matching the upstream vesin
allocation-reuse contract. Thread-local storage keeps NEB's parallel
per-image force path race-free. Fixes the ASV regressions from the #386
vesin port (point / min / saddle / NEB wall times).
