Classical pair pots (LJ, Morse, LJCluster, QSC) re-use a long-lived
``eonc::VesinNeighbors`` member and no longer free the list before every
force evaluation, matching the vesin ``vesin_neighbors`` allocation-reuse
contract. Fixes the ASV regressions introduced with the #386 vesin port
(point / min / saddle / NEB wall times).
