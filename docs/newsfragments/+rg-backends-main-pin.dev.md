The rgmin and rgsaddle CI job builds rgsaddle main 371dac5 (C ABI minor 25) and rgmin 0.5.2 instead of rgsaddle 0.2.2 and rgmin 0.4.0, so the band exp metric and ODE12r stepper, the minor 21 band flag and the minor 22 dimer reset and Lanczos loop are compiled and tested there. Its compile step requires each of those rgmin and rgsaddle features to be reported as enabled, not only listed.
