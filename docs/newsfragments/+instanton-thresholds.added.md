`[Instanton] collapse_fraction` (default 1e-4) sets the fraction of the starting ring's B_N below which a collapsing rate search stops, and `[Instanton] rotation_zero_fraction` (default 0.1) the fraction of the softest vibration at or below which a reactant rotation counts as a zero mode. Both sit in the INI and JSON readers, `config.yaml`, `eon_schema.InstantonConfig` and the instanton guide.
