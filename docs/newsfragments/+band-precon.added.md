`[Nudged Elastic Band]` gains `band_precon`, `band_precon_mu` and `band_stepper` for the rgsaddle band. `band_precon = exp` installs the exponential metric of Makri, Ortner and Kermode (2019), and `band_stepper = ode12r` runs the ODE12r stepper. Both are off by default and need eOn built against rgsaddle 0.3.0 or newer; eOn compiled against an older rgsaddle refuses them. The metric is refused with `solid_state`, one atom per image, `energy_weighted` and `onsager_machlup`.
