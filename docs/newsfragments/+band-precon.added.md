`[Nudged Elastic Band]` can run the rgsaddle band as ODE12r-Exp (Makri, Ortner and Kermode, J. Chem. Phys. 150, 094109 (2019)). `band_precon = exp` calls `rgsaddle_band_set_exp_precon` and `band_stepper = ode12r` selects `RGSADDLE_METHOD_ODE12R`. `band_precon_A`, `band_precon_mu`, `band_precon_r_cut_factor` and `band_precon_c_stab` are that function's arguments; 0 keeps the library defaults (A 3, estimated mu, cutoff 2 r_nn, C_stab 0.1). The keys default to `none`, `auto` and 0, so an input that does not set them is the stock band. The C API has no absolute cutoff, no shift, and no ODE12r tolerance arguments, so those are not options. `exp` is refused with fixed atoms (no mask in the C API), `solid_state`, one atom per image, `energy_weighted` and `onsager_machlup`. The keys need rgsaddle 0.3.0 or newer and C ABI minor 22.
