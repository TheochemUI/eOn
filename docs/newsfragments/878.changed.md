eOn requires rgpot 3.7.0 or newer, up from 3.5.1: the eam backend uses `rgpot::EAMTablePot` and its `skin` option. rgpot 3.6.0 added the EAM table potential without `skin`. The wrap builds rgpot with `-Dwith_eam_table=true`, and an installed rgpot has to define `RGPOT_HAS_EAM_TABLE`. rgpot 3.7.0 is soversion 6, so the pyeonclient wheel bundles it as `libeon_rgpot.so.6`.
