Windows wheels find Eigen through a host prefix that also provides pkg-config, flang 19, and capnp. MinGW, Git's ucrt64 toolchain, and Strawberry stay off PATH so the MSVC CMake probe can finish. Git's sh stays on PATH after the MSVC linker, including the /usr/bin mount Git bash prepends. When flang rejects Meson's Fortran probe, the wheel links FortranRuntime from the compiler's library directory. ExtPot, the LAMMPS plugin, and eonclib are static libraries on Windows so the Python extension can link their C++ symbols. Metatomic tests copy torch's DLLs beside the relax engine so a pixi runtime cannot satisfy a torch import.
