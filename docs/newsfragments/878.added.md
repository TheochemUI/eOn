`[RgpotPot] backend = eam` evaluates a tabulated embedded-atom potential through rgpot. `table_path` names a LAMMPS funcfl, setfl or eam/fs table, `table_format` picks the layout (`setfl` by default), and `neighbor_skin` sets the pair-list skin in Angstrom. The three keys are in `config.yaml`, the `eon-schema` models and the INI, JSON and SSoT projections. A relative `table_path` in a `config.ini` is resolved against that file's directory when the file is loaded.
