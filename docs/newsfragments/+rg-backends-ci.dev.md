A CI job builds the client against rgmin and rgsaddle and runs the eon test suite, with unit tests that an rgmin relaxation and an rgsaddle CI-NEB on LJ13 converge and count every force call. In that build the dimer and Lanczos rotations run in rgsaddle, so the eOn 3.5.0 min-mode force-call pins are skipped there; those cases still check convergence, exact call accounting, and that the search reaches one of the two known saddles.
